# MS Dhoni Cricket Career Dashboard – Power BI
## Project Overview
This project focuses on analyzing MS Dhoni's complete cricket career performance using Power BI. The dashboard provides interactive visualizations to explore his batting and fielding performance across different cricket formats.

## Objectives
- Analyze MS Dhoni's career statistics across different formats.
- Understand year-wise batting performance.
- Compare IPL season-wise performance.
- Identify batting and fielding performance trends.

## Tools & Technologies
- Power BI
- Microsoft Excel
- Power Query
- DAX
- Data Visualization

## Dataset Details
The project includes the following datasets:
- Career Summary
- Year-wise Performance
- IPL Season-wise Performance
- Fielding Summary

## Key Performance Indicators (KPIs)
- Total Matches
- Total Runs
- Batting Average
- Strike Rate
- Centuries and Half-Centuries
- Catches and Stumpings

## Dashboard Features
- Interactive KPI cards.
- Format-wise performance analysis.
- Year-wise batting performance trends.
- IPL season-wise performance analysis.
- Fielding statistics visualization.
- Interactive filters and slicers.

## Project Files
- Power BI Dashboard (.pbix)
- Cricket Career Dataset (.xlsx)
- Dashboard Screenshots

## Expected Outcome
To transform cricket statistics into meaningful visual insights and understand MS Dhoni's career performance through interactive data visualization.
